# 📋 Возможности приложения EmployeeWorkTracker (Work Tracker)

На основе всей нашей работы над проектом, это полноценное WPF-приложение для рабочего стола, написанное на C# с использованием архитектуры MVVM. Вот полный список функций:

---

## 1. 🧑‍💼 Управление сотрудниками (База данных)

- **Полный CRUD**: Добавление, редактирование и удаление профилей сотрудников
- **Поиск и фильтрация**: Мгновенный поиск по имени или номеру паспорта
- **Детальные профили**: Хранение фамилии, имени, отчества, номера паспорта, должности и комментариев
- **Контактная информация**: Телефонные номера с выбором кода страны (🇨🇿 Чехия, 🇺🇦 Украина, 🇷🇺 Россия, 🇸🇰 Словакия, 🇵🇱 Польша, 🇩🇪 Германия)
- **Фотографии**: Загрузка и удаление фото профиля сотрудника
- **Настройка оплаты**: Индивидуальная настройка типа оплаты (почасовая ставка или фиксированная сумма)
- **Быстрые действия**: Копирование номера паспорта одним кликом с плавной анимацией бейджа "Скопировано"

---

## 2. 💰 Обработка начислений зарплаты

- **Поиск сотрудника**: Поиск по номеру паспорта для начала начисления
- **Умный ввод дат**: Кастомные поля ввода дат с строгой валидацией (дд.мм.гггг) — автоматически вставляют точки и не дают ввести некорректные даты (например, 32 день или 13 месяц)
- **Несколько мест работы**: Добавление нескольких рабочих адресов (Город, Адрес, Объект) за один период
- **Несколько фото росписок**: Загрузка **множества** фото в качестве подтверждения получения денег
- **Комментарии**: Добавление подробных комментариев (до 3000 символов) со счётчиком символов в реальном времени

---

## 3. 📊 Отчёты и аналитика

- **История выплат**: Просмотр списка всех обработанных начислений с фото сотрудников и превью росписок
- **Расширенная фильтрация**: Поиск и фильтрация отчётов по номеру паспорта или дате создания
- **Детальный просмотр**: Открытие окна с полной информацией — сотрудник, период работы, места работы, комментарии и все фото росписок
- **Редактирование после сохранения**: Добавление или удаление фото росписок прямо из просмотра отчёта
- **Управление записями**: Удаление записей о начислениях при необходимости

---

## 4. 🌍 Мультиязычность (Локализация)

- **4 языка**: Полный перевод интерфейса на **Английский, Русский, Украинский и Чешский**
- **Мастер первого запуска**: Специальное приветственное окно с выбором языка при самом первом запуске
- **Мгновенное переключение**: Смена языка в настройках — интерфейс обновляется сразу, без перезапуска приложения
- **Сохранение настроек**: Выбранный язык сохраняется локально в `AppData/settings.json` и восстанавливается при следующих запусках

---

## 5. 🎨 Современный UI/UX дизайн

- **Кастомная тёмная тема**: Стильный тёмный режим с использованием специальных цветов (например, `#1A1A1A`, `#252525`, `#66BB9A` для акцентов)
- **Кастомное окно**: Безрамочное окно с кастомным заголовком, перетаскиванием мышью и собственными кнопками Свернуть/Развернуть/Закрыть
- **Боковая панель навигации**: Чистая иконочная панель для быстрого доступа к разделам: Главная, Сотрудники, База данных, Зарплата, Отчёты, Настройки
- **Строка состояния**: Нижняя панель со статусом приложения и номером версии
- **Анимации**: Плавные эффекты при наведении, fade-in и slide-up для обратной связи с пользователем

---

## 6. 🏗️ Архитектура и хранение данных

- **Паттерн MVVM**: Построено на базе `CommunityToolkit.Mvvm` для чистого разделения UI и логики
- **Material Design**: Используется `MaterialDesignInXaml` для иконок и базовых стилей
- **Локальное хранение**: Кастомный `DatabaseService` для хранения данных о сотрудниках и выплатах локально (JSON-файлы в папке `AppData`) — не требует подключения к интернету или внешней базы данных
- **Полностью офлайн**: Всё работает без интернета

---

## 🎯 Итог

Это полностью автономное, локализованное и визуально отполированное десктопное приложение для:
- 📋 Управления персоналом
- 📍 Отслеживания мест работы
- 💵 Обработки зарплатных начислений
- 📸 Цифрового учёта росписок о получении денег

Приложение готово к использованию и легко масштабируется для добавления новых функций! 🚀
